# Henna Nirali - Gallery

## Add more photos

1. Put the photo inside the `images` folder.
2. Open `gallery.js`.
3. Add one line to `galleryImages`, for example:

   `{ file: "images/henna-003.jpg", alt: "Bridal henna design" },`

4. Commit the changes to GitHub.

## GitHub Pages

Upload all files in this folder to a GitHub repository and enable GitHub Pages from:

Settings → Pages → Deploy from a branch → main → / (root)

Your gallery will then have a public URL that anyone can view without a GitHub account.

After the final GitHub Pages URL is known, create a QR code pointing to that URL. The QR code can be printed on your business card or flyer.
